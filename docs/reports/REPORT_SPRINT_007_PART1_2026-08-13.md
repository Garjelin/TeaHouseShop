## Цели первой половины спринта 7

Согласно плану, спринт 7 целиком закрывает расширенный поиск: фильтры, сортировку, debounce, историю и автодополнение. В **первой половине** в фокусе:

1. Убрать заглушку `TODO` в `searchProductsWithFilters` и сделать **реальный поиск по каталогу**.
2. UI фильтров: **категория**, **цена**, **рейтинг**.
3. **Сортировка** результатов.
4. **Debounce** ввода, чтобы не дергать данные на каждый символ.

Отложено на **вторую половину**: персистентная история поиска (DataStore), более развитое автодополнение.

## Что было до изменений

1. Экран поиска существовал, но опирался на `searchProductsWithFilters`, который в `ProductLocalSourceImpl` вызывал **`TODO(...)`** — поиск с фильтрами падал при реальном использовании.
2. Подсказки были захардкожены (`Laptop`, `Phone`, …) и не относились к чайному каталогу.
3. История поиска жила только в `MutableStateFlow` ViewModel (это сохранено как временное решение).

## Как проверить

1. Открыть вкладку **Поиск**.  
2. Ввести часть названия чая — результаты появляются с задержкой (debounce).  
3. Выбрать категорию / рейтинг / диапазон цены — список сужается.  
4. Сменить сортировку (цена ↑/↓, рейтинг, название).  
5. Нажать подсказку или Enter (Search) — запрос попадает в «Недавние» (до перезапуска приложения).

---

## Известные ограничения

1. История поиска **не переживает** перезапуск приложения.  
2. Фильтрация выполняется в памяти поверх полного списка товаров (ок для текущего каталога; при росте — SQL в DAO).  
3. Подсказки — только по `title`, без fuzzy/транслита.
