## Как проверить

1. Войти в аккаунт (тот же, под которым оформляли заказ).  
2. Оформить заказ из корзины (если ещё нет).  
3. Открыть **Профиль** → блок **История заказов**.  
4. Нажать на заказ → экран с адресом, оплатой, позициями и суммой.  
5. «Обновить» перечитывает список из DataStore.

---

## Известные ограничения

1. **Нет синхронизации с сервером** — заказы только локально.  
2. **Гостевые заказы (`userId = 0`)** не видны в профиле после входа под другим id (как и гостевая корзина).  
3. История доступна только авторизованному пользователю (профиль редиректит гостя на логин).
